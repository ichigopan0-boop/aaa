# 3d

## ぶっとばしボール

`index.html` をブラウザで開くだけで遊べる、上から見た2D乱闘ゲームです。

- 島に落ちているボールを拾って敵にぶつけ、浮島から落とす
- 当たるとダメージ％がたまり、％が高いほどよく吹っ飛ぶ（スマブラ風）
- ボールはいくつでも持てる（持つほど重くて遅くなる）
- 投げると持っている球を全部連射。n個目の球はn倍の強さ（ダメージ％もふっとびもn倍）
- 島は時間がたつとだんだん小さくなる。3機なくなったら負け
- ダッシュ（無敵回避）・たいあたり・ガード（球をはじき返す）

### モード
- **CPU戦**：CPU 1〜3体、強さ（よわい / ふつう / つよい）を選べる
- **オンライン対戦**：「部屋をつくる」で出る4文字の部屋コードを友だちに教えると、最大4人で対戦できる（PeerJS の無料接続サーバーを使用。インターネット接続が必要）

### 操作
| | パソコン | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面の左半分をドラッグ |
| ねらう・投げる | マウスでねらって左クリック（J） | 右の赤いスティックを引っぱって離す（タップだけなら一番近い敵へ） |
| ダッシュ | スペース / Shift / K | ダッシュボタン |
| たいあたり | 右クリック / E / L | たいあたりボタン |
| ガード | Q / F / I | ガードボタン |
| メニュー | Esc | ⏸ボタン |

### 友だちとURLで遊ぶには
GitHub の Settings → Pages で このブランチ（ルート）を公開すると、`https://<ユーザー名>.github.io/aaa/` で遊べます。
ロビーの「招待リンクをコピー」で、部屋コード入りのリンクを送れます。
