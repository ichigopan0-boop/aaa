# アストラの大地 〜目覚めし古代機兵〜

ブラウザで遊べる3Dオープンワールド・アクションRPG（トゥーン調）。
PC（キーボード＋マウス）とスマホ（タッチ）に対応。オンラインで最大4人の協力・対戦プレイができます。

## 遊び方
- `index.html` をブラウザで開くだけで起動します（Chrome / Edge / Safari 推奨）。
- オンライン機能はインターネット接続が必要です（PeerJSの無料中継サーバーで接続し、通信はP2P）。

## 友達と遊ぶ（オンライン）
1. ホスト役：タイトルで「ホストになって友達と遊ぶ」を選ぶと、6文字のルームコードが表示されます（メニュー→システムでも確認可）。
2. 参加する人：「友達のワールドに参加」でコードを入力します（最大4人）。
3. 協力プレイでは敵・ボス・時間・天気を共有。宝箱や祠などの進行は各自のセーブに記録されます。
4. ホストはメニュー→システムで「対戦モード（PvP）」を切り替えられます。
- 会社や学校などの厳しいネットワークでは接続できない場合があります。
- 友達に配るときは、このフォルダをそのまま渡すか、GitHub Pages などで公開すると便利です。

## 目的
古城跡で暴走する「暴走機神オメガ」を倒すこと。最初から挑めますが非常に強いため、
祈りの祠・観測塔・各地の主・封印の剣・古代兵装・レベルアップ・スキルで強くなってから挑みましょう。

## 主な要素
- 8つの地域（はじまりの野・迷いの森・白嶺山脈・ほむら火山・ミナモ湖・かぜの平原・ゴウセキ峡谷・古城跡）
- 昼夜・天気（雨・雷雨・雪）、崖登り、パラセール、泳ぎ、馬
- 片手剣・両手剣・槍・弓・魔法ロッド（耐久度あり）、6種類の矢
- 経験値レベル＋スキルツリー、料理、ショップ、女神像
- 祈りの祠16、観測塔8、各地の主5、宝箱、森の精の実
- オンライン：ルームコードで最大4人、協力（敵・ボス・時間・天気を共有）＋対戦モード、チャット、スタンプ、ピン共有、仲間の蘇生

## 操作（PC）
| 操作 | キー |
|---|---|
| 移動 | WASD |
| 視点 | マウス |
| 攻撃（長押しで回転斬り） | 左クリック |
| 弓を構える→撃つ | 右クリック長押し→左クリック |
| ジャンプ／パラセール | Space |
| ダッシュ | Shift |
| 回避 | C（ロックオン中は Space） |
| ロックオン | Q |
| 魔法 | E |
| 調べる・話す | F |
| しゃがむ | Z |
| 回復 | R |
| 武器切替 | 1 / 2 / 3、矢の種類 X |
| 馬笛 | H |
| メニュー／マップ | Tab / M |
| チャット／スタンプ | Enter / V |

## 構成
- `index.html` / `css/style.css`
- `js/core` 共通処理・入力・サウンド
- `js/data` アイテム・ワールド配置・会話
- `js/world` 地形・空・水・植生・建物・天気・当たり判定
- `js/entities` プレイヤー・敵・ボス・馬・動物・NPC・拾い物・投射物・モデル
- `js/systems` 成長・カメラ・戦闘・祠・クエスト・通信
- `js/ui` HUD・会話・メニュー・地図・タッチ操作・タイトル
- `lib/` three.js r149、PeerJS 1.5.4（どちらもMITライセンス）
